# 28-Day Interview Preparation Plan (5 hours/day)

## Daily routine (5 hours)
- 60 min: SQL practice
- 60 min: Python/Pandas practice
- 120 min: project build
- 45 min: Power BI learning/build
- 15 min: explain one result aloud / interview notes

## Week 1: foundations and data quality
Day 1: Set up project; inspect CSVs; write down business problem and KPIs.
Day 2: SQL SELECT, WHERE, ORDER BY, LIMIT; solve 10 small queries.
Day 3: SQL GROUP BY, HAVING, COUNT, SUM, AVG.
Day 4: SQL INNER/LEFT JOIN; understand primary and foreign keys.
Day 5: Python data types, missing values, duplicates, Pandas read_csv/info/describe.
Day 6: Clean sales data and document every decision.
Day 7: Review week; explain data cleaning and joins aloud.

## Week 2: analysis
Day 8: Revenue, estimated cost, estimated gross profit and margin.
Day 9: Monthly trend and month-over-month change.
Day 10: Product/category performance.
Day 11: Region and channel performance.
Day 12: Inventory snapshot and reorder flags; state limitations.
Day 13: Load data to SQLite and solve 6 SQL business questions.
Day 14: Write 5 evidence-based findings and 3 recommendations.

## Week 3: Power BI
Day 15: Install/open Power BI Desktop (Windows) or choose Power BI Service/browser access if on Mac; check current availability and limitations.
Day 16: Import CSVs; set data types and create relationships.
Day 17: Build KPI cards and monthly revenue line chart.
Day 18: Build product/category and channel charts.
Day 19: Build region comparison and slicers.
Day 20: Build inventory reorder table with conditional formatting.
Day 21: QA totals against SQL/Pandas; improve labels, titles and accessibility.

## Week 4: portfolio and interview
Day 22: Finalize README and data dictionary.
Day 23: Capture dashboard screenshots and publish code to GitHub.
Day 24: Practice SQL joins, aggregation and duplicate detection.
Day 25: Practice Python/Pandas cleaning and groupby questions.
Day 26: Practice KPI definitions, dashboard design and business cases.
Day 27: Mock interview: project walkthrough, career gap, internship, strengths.
Day 28: Final mock interview; revise resume for each target job.

## Ready-to-apply checklist
- You can explain each cleaning choice.
- SQL answers reproduce dashboard totals.
- You can define each KPI without hesitation.
- Dashboard has clear filters and no misleading metrics.
- GitHub README explains problem, method, findings and limitations.
- Resume claims only skills you can demonstrate.
